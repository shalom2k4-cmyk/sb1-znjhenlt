# Mperekeza - Design System & Figma

## Overview
Mperekeza is a FemTech mobile app designed for the Rwandan market, focusing on reproductive health, HIV prevention, and menstrual cycle tracking in Kinyarwanda.

## Design System

### Color Palette
- **Primary (Teal)**: #14B8A6 - Trust, health, growth
- **Secondary (Rose)**: #F43F5E - Menstruation phase, menstrual health
- **Accent (Orange)**: #F97316 - Ovulation phase, fertility window
- **Tertiary (Violet)**: #8B5CF6 - Luteal phase, emotional support
- **Neutral**: Slate grays (#1E293B to #F1F5F9)
- **Success**: #10B981 - Confirmation, saved data
- **Warning**: #EAB308 - Alerts, important info

### Typography
- **Headings**: 600-700 weight
- **Body**: 400 weight
- **Labels**: 500-600 weight
- **Small text**: 400 weight

### Spacing
8px grid system throughout:
- xs: 4px
- sm: 8px
- md: 16px
- lg: 24px
- xl: 32px

### Components
- **Cycle Ring**: 200x200px progress indicator
- **Cards**: 16px border radius, subtle shadows
- **Buttons**: 12-14px border radius, active scale effects
- **Modal**: Bottom sheet design, rounded top corners
- **Bottom Nav**: 5 tab navigation with icons

## Prototype Preview

**Homepage Features:**
- Cycle progress ring showing day 1-28
- Phase indicator (Menstruation, Follicular, Ovulation, Luteal)
- Daily insight with emoji, title, message, and tips
- "Did you know" fact carousel
- 28-day calendar with color-coded phases
- Health logging button

**Insights Page:**
- Category filter (All, HIV Prevention, Hygiene, Future Planning)
- Article cards with images and read times
- Deep-dive content pages

**Tracker Page:**
- Monthly calendar view
- Day selection and mood/flow/symptom logging
- Recent logs history

**Consultation Page:**
- Doctor profiles with ratings and availability
- Real-time chat interface
- Location and specialization info

**Settings Page:**
- Anonymous mode toggle
- Privacy controls
- Notification preferences
- About & feedback
